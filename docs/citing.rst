Citing Hexapla
==============

If you use Hexapla in your research, please cite it. The repository's ``CITATION.cff`` file has the details, and
GitHub shows a citation for it under "Cite this repository":

    Turnbull, Robert. *Hexapla: static websites for reading and exploring word-aligned manuscript texts*.
    Version 0.1.0. https://github.com/rbturnbull/hexapla

.. code-block:: bibtex

    @software{turnbull_hexapla,
      author  = {Turnbull, Robert},
      title   = {Hexapla: static websites for reading and exploring word-aligned manuscript texts},
      version = {0.1.0},
      url     = {https://github.com/rbturnbull/hexapla},
    }

Please also cite the sources of a site's texts, parses and alignments, as its About page and manuscript pages
describe them.
